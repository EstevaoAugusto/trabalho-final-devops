# Descrição do Trabalho

Olá, pessoal!

O trabalho final da disciplina consiste em construir um pipeline de CI/CD completo para um microsserviço.

O que deve ser feito

- Microsserviço: desenvolver um microsserviço de backend, com tema e linguagem à escolha de vocês.
- Pipeline de CI/CD: criar o pipeline do microsserviço com, obrigatoriamente, as seguintes etapas:
  - Teste
  - Build
  - Deploy
- Manifestos Kubernetes: criar os manifestos K8s necessários para o deploy da aplicação.
    - Nomad: criar também os arquivos de job para o deploy da aplicação no Nomad.
    - Vídeo: gravar um vídeo explicando o funcionamento do CI/CD, mostrando o pipeline e cada uma das etapas.

O que deve ser entregue

- Link do repositório com o código do microsserviço, o pipeline, os manifestos K8s e os arquivos do Nomad
- Vídeo gravado (arquivo ou link)

Avaliação

- 50% da nota: vídeo explicativo
- 50% da nota: arquivos entregues (repositório, pipeline, manifestos etc.)

Prazo de entrega: 10 dias, até quinta-feira, 03/12/2026, às 23h59.
